# python_labs

Лабораторные работы по программированию на Python для МИСИС.

## Структура

```
python_labs/
├─ src/
│  ├─ lab01/     → см. src/lab01/README.md
│  ├─ lab02/     → см. src/lab02/README.md
│  ├─ lab03/     → см  src/lab03/README.md
│  ├─ lab04/     → см  src/lab04/README.md
│  ├─ lab05/     → см  src/lab05/README.md
│  ├─ lab06/     → см  src/lab06/README.md
│  ├─ lab07/     → см  src/lab07/README.md
|  └─   lib/
├─ data/         (входные и выходные файлы по лабам: lab04/, lab05/, lab06/, lab07/)
├─ images/       (скриншоты)
└─ requirements.txt   (openpyxl — для ЛР5)
```
