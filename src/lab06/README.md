# ЛР6 CLI команды для текста и конвертации

## Цель и структура

CLI позволяет вызвать действие программы через команду и параметры. `cli_text.py` содержит `cat` и `stats`; `cli_convert.py` — `json2csv`, `csv2json`, `csv2xlsx`. Обработка текста переиспользует ЛР3 и ЛР4, конвертация — ЛР5. Собственной копии алгоритмов конвертации в CLI нет.

Запускать команды из корня `python_labs`. Для Excel один раз установить зависимость ЛР5:

```powershell
python -m pip install -r requirements.txt
```

## Команды и параметры

| Команда | Параметры | Назначение |
|---|---|---|
| cat | `--input PATH` обязательно, `-n` необязательно | Построчно вывести текст; флаг добавляет номера |
| stats | `--input PATH` обязательно, `--top N` необязательно, по умолчанию 5 | Число слов, уникальные и топ частот |
| json2csv | `--in PATH --out PATH`, оба обязательны | JSON → CSV |
| csv2json | `--in PATH --out PATH`, оба обязательны | CSV → JSON; значения остаются строками |
| csv2xlsx | `--in PATH --out PATH`, оба обязательны | CSV → книга Excel |

`add_subparsers` создаёт группу команд, `add_parser` — конкретную команду, `add_argument` — параметр. `parse_args` возвращает Namespace. Для `--in` используется `dest="input"`, поскольку `in` — ключевое слово Python. `--top` преобразуется в int; отрицательные значения отклоняются, 0 допустим и даёт пустой топ.

## Справка всех подкоманд

```powershell
python -m src.lab06.cli_text --help
python -m src.lab06.cli_text cat --help
python -m src.lab06.cli_text stats --help
python -m src.lab06.cli_convert --help
python -m src.lab06.cli_convert json2csv --help
python -m src.lab06.cli_convert csv2json --help
python -m src.lab06.cli_convert csv2xlsx --help
```

Все семь вызовов проверены и завершились с кодом 0. Для `--help` не нужны входные файлы и установленный openpyxl: импорт XLSX находится только в ветке выбранной команды.

## Примеры запуска и фактический вывод

```powershell
python -m src.lab06.cli_text cat --input data/lab06/samples/demo_simple.txt -n
```

```text
1: Привет, мир! Привет!
2: Кот и пёс гуляют.
```

```powershell
python -m src.lab06.cli_text stats --input data/lab06/samples/demo_simple.txt --top 3
```


```powershell

python -m src.lab06.cli_convert csv2json --in data/lab06/samples/demo_people.csv --out data/lab06/out/demo_from_csv.json
python -m src.lab06.cli_convert csv2xlsx --in data/lab06/samples/demo_people.csv --out data/lab06/out/demo_people.xlsx
```

Три команды выполнены успешно. Результаты: [CSV](../../data/lab06/out/demo_from_json.csv), [JSON](../../data/lab06/out/demo_from_csv.json), [XLSX](../../data/lab06/out/demo_people.xlsx). Имена результатов различаются с исходными, поэтому примеры можно запускать повторно.

## Проверки и ошибки

```powershell
python -m src.lab06.test_cases
```

Фактический результат: **8 тестов, OK**. Проверяются справка, нумерация и переводы строк, статистика, три конвертации, ошибки путей/кодировки/аргументов, защита одинакового пути, кавычки и пустые значения CSV. Повреждённый CSV проверяется на повтор заголовков и лишние/недостающие поля; ошибка возникает до открытия выхода, старый выход сохраняется.

Ошибки `argparse` и ожидаемые ошибки файлов/данных выводятся через `parser.error` в stderr и завершают процесс с кодом 2. При успехе код 0. Библиотечные функции могут поднимать FileNotFoundError, ValueError, UnicodeDecodeError и csv.Error; CLI превращает их в понятное сообщение.

## Расширение содержимое и ограничения

- cat/stats читают UTF-8 без ограничения расширения. `.py` выводится как текст, не исполняется. `.csv` тоже обычный текст. Настоящие EXE/XLSX не становятся текстом от переименования; возможна ошибка декодирования.
- json2csv требует .json → .csv, csv2json — .csv → .json, csv2xlsx — .csv → .xlsx; регистр расширения не важен. Содержимое всё равно проверяется соответствующим парсером.
- JSON→CSV принимает непустой список словарей; недостающие поля пустые. None становится пустым полем, вложенные значения — текстовым представлением, типы полностью не восстанавливаются.
- CSV ожидается с запятой и заголовком. У csv2json нужна хотя бы одна запись, у csv2xlsx допускается только заголовок. Для неизвестной схемы нельзя надёжно распознать произвольную первую строку как данные вместо заголовка.
- Одинаковый разрешённый путь ввода/вывода отклоняется до записи. Жёсткие ссылки отдельно не проверяются. Существующий выход может быть перезаписан; атомарной записи нет.
- `main(argv=None)` позволяет тестировать разбор аргументов. `subprocess.run` в тестах запускает настоящую команду, `cwd=ROOT` задаёт корень, `-X utf8` стабилизирует русский текст на Windows.
